GitHub Pages + Cardmarket Auto-Load

Damit iPhone/Mac die Dateien laden:

1. Öffne die Seite über GitHub Pages, z. B.
   https://DEINNAME.github.io/DEINREPO/

2. Nicht öffnen über:
   https://github.com/DEINNAME/DEINREPO/blob/main/index.html

3. Im gleichen Ordner wie index.html müssen liegen:
   price_guide_18.json
   products_singles_18.json

4. Dateinamen müssen exakt stimmen.
   GitHub Pages unterscheidet Groß-/Kleinschreibung.

5. Nach Upload auf GitHub Pages ein paar Minuten warten und Safari neu laden.

6. Die App zeigt jetzt oben eine Cardmarket-Statusanzeige:
   grün = geladen
   gelb = lädt/sucht
   rot = Dateien nicht gefunden
